# Synthetic anatomy render evidence

2026-09-05. These images render the actual `SkeletonAnatomyModel` SceneKit geometry with a synthetic upright set of tracked landmark positions. They establish the model's visual form, including skull, ribcage, spine, pelvis and limbs. They are not camera captures, physical body-alignment evidence, a playable-app screenshot, or performance measurements.

The mesh is original/procedural, reusable and retargeted from observed body landmarks. Hand and foot detail is a neutral cosmetic template attached to tracked endpoints; individual fingers and toes are not claimed as sensed joints or colliders.

- [Front view](skeleton-front.png)
- [Three-quarter view](skeleton-three-quarter.png)

The native source and renderer tests are the implementation authority; these images can be regenerated when the geometry changes. Remaining physical/interaction gates are recorded in the roadmap and build log.
